# Zorilad

Веб-приложение внутреннего пути: приветствие, пять стихий и закрытый раздел «Эфир».

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на `http://127.0.0.1:8080`.

## Перед публикацией

Оплата Эфира сейчас только в браузере (`localStorage`, ключ `zorilad-ether`). Это проверка, не продажа. Перед Google Play замени её на Google Play Billing. Иначе доступ открывается без оплаты, а магазин отклонит приложение за обход своей кассы.

Тексты используют образы Naruto (Хокаге, Саске, Сакура, Девятихвостый). Это чужой товарный знак. Для магазина безопаснее свои имена, иначе возможны жалоба и снятие.
